🧪 ქიმიის ინტერაქტიული გზამკვლევი

არაორგანულ ნაერთთა ძირითადი კლასები და ექსპერიმენტები

🔥 1. ოქსიდები

განმარტება: ოქსიდი არის რთული ნივთიერება (ორელემენტიანი ნაერთი), რომელიც შედგება ორი ქიმიური ელემენტისგან, რომელთაგან ერთ-ერთი ჟანგბადია (-2 ჟანგვის ხარისხით).

კლასიფიკაცია და გრაფიკული ფორმულები

ტიპი ფორმულა სახელწოდება გრაფიკული (სტრუქტურული) ფორმულა
ფუძე ოქსიდი Na₂O ნატრიუმის ოქსიდი Na — O — Na
ფუძე ოქსიდი CaO კალციუმის ოქსიდი Ca = O
მჟავა ოქსიდი CO₂ ნახშირბადის (IV) ოქსიდი O = C = O
მჟავა ოქსიდი SO₃ გოგირდის (VI) ოქსიდი O = S(=O) = O
ამფოტერული Al₂O₃ ალუმინის ოქსიდი O = Al — O — Al = O
ამფოტერული ZnO თუთიის ოქსიდი (ცინკის ოქსიდი) Zn = O

მიღება და ქიმიური თვისებები

  • მიღება (მარტივი ნივთიერების ჟანგვა/წვა): 2Mg + O₂ → 2MgO
  • ფუძე ოქსიდის ურთიერთქმედება წყალთან: CaO + H₂O → Ca(OH)₂
  • მჟავა ოქსიდის ურთიერთქმედება წყალთან: SO₃ + H₂O → H₂SO₄

🍋 2. მჟავები

განმარტება: რთული ნივთიერებები, რომლებიც შედგება მეტალის ატომით ჩანაცვლების უნარის მქონე წყალბადის ატომებისა და მჟავას ნაშთისგან.

კლასიფიკაცია და ფუძიანობა

ფორმულა სახელწოდება ფუძიანობა ჟანგბადიანობა გრაფიკული ფორმულა
HCl მარილმჟავა (ქლორწყალბადმჟავა) ერთფუძიანი უჟანგბადო H — Cl
HNO₃ აზოტმჟავა ერთფუძიანი ჟანგბადიანი H — O — N(=O)=O
H₂SO₄ გოგირდმჟავა ორფუძიანი ჟანგბადიანი H — O — S(=O)₂ — O — H
H₃PO₄ ორთოფოსფორმჟავა სამფუძიანი ჟანგბადიანი (H—O)₃ — P = O

მიღება და ქიმიური თვისებები

  • ურთიერთქმედება მეტალებთან (ძაბვის მწკრივში H-მდე მდგომი): Zn + 2HCl → ZnCl₂ + H₂↑
  • ურთიერთქმედება ფუძეებთან (ნეიტრალიზაცია): NaOH + HCl → NaCl + H₂O
  • მჟავას მიღება (მჟავა ოქსიდი + წყალი): P₂O₅ + 3H₂O → 2H₃PO₄

🧼 3. ფუძეები (ჰიდროქსიდები)

განმარტება: რთული ნივთიერებები, რომლებიც შედგება მეტალის ატომისა (ან ამონიუმის იონის NH₄⁺) და ერთი ან რამდენიმე ჰიდროქსილის (OH⁻) ჯგუფისგან.

სახელწოდება და სტრუქტურა

ფორმულა სახელწოდება ტიპი (ხსნადობა) გრაფიკული ფორმულა
NaOH ნატრიუმის ჰიდროქსიდი (მწვავე ნატრიუმი) ტუტე (კარგად ხსნადი) Na — O — H
Ca(OH)₂ კალციუმის ჰიდროქსიდი (ჩამქრალი კირი) ტუტე (მცირედ ხსნადი) H — O — Ca — O — H
Cu(OH)₂ სპილენძის (II) ჰიდროქსიდი უხსნადი ფუძე H — O — Cu — O — H

მიღება და ქიმიური თვისებები

  • ტუტის მიღება (აქტიური ტუტე მეტალი + წყალი): 2Na + 2H₂O → 2NaOH + H₂↑
  • უხსნადი ფუძის მიღება: CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄
  • უხსნადი ფუძის თერმული დაშლა: Cu(OH)₂ → CuO + H₂O

🌈 4. ინდიკატორები

განმარტება: ნივთიერებები, რომლებიც იცვლიან ფერს ხსნარის არის (მჟავა, ტუტე, ნეიტრალური) მიხედვით.
ინდიკატორი ნეიტრალური არე (pH = 7) მჟავა არე (H⁺, pH < 7) ტუტე არე (OH⁻, pH > 7)
ლაკმუსი იასამნისფერი წითელი ლურჯი
ფენოლფთალეინი უფერო უფერო ჟოლოსფერი
მეთილნარინჯი (მეთილორანჟი) ნარინჯისფერი ვარდისფერი / წითელი ყვითელი

🔬 ინტერაქტიული ლაბორატორია: შეამოწმე ინდიკატორი

აირჩიეთ ინდიკატორი და არე, რათა დააკვირდეთ ფერის ცვლილებას ჭურჭელში:

H₂O
ხსნარის შეფერილობა: იასამნისფერი

🧂 5. მარილები

განმარტება: რთული ნივთიერებები, რომლებიც შედგება მეტალის კატიონებისა (ან ამონიუმის NH₄⁺) და მჟავას ნაშთის ანიონებისგან.

მაგალითები და გრაფიკული ფორმულები

  • NaCl (ნატრიუმის ქლორიდი — სუფრის მარილი): Na — Cl
  • CaSO₄ (კალციუმის სულფატი — თაბაშირი): Ca = (O₂) = S(=O)₂
  • Na₂CO₃ (ნატრიუმის კარბონატი — კალცინირებული სოდა): Na — O — C(=O) — O — Na

მარილების მიღების 10 ძირითადი ხერხი

  1. მეტალი + არამეტალი: 2Na + Cl₂ → 2NaCl
  2. მეტალი + მჟავა: Mg + H₂SO₄ → MgSO₄ + H₂↑
  3. მეტალი + მარილი: Fe + CuSO₄ → FeSO₄ + Cu
  4. ფუძე ოქსიდი + მჟავა ოქსიდი: CaO + CO₂ → CaCO₃
  5. ფუძე ოქსიდი + მჟავა: CuO + H₂SO₄ → CuSO₄ + H₂O
  6. მჟავა ოქსიდი + ტუტე: CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O
  7. მჟავა + ფუძე (ნეიტრალიზაცია): KOH + HNO₃ → KNO₃ + H₂O
  8. მჟავა + მარილი: Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑
  9. ტუტე + მარილი: 2NaOH + FeCl₃ → Fe(OH)₃↓ + 3NaCl
  10. მარილი + მარილი (მიმოცვლის რეაქცია): AgNO₃ + NaCl → AgCl↓ + NaNO₃
